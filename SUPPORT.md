# Support

NotYVOS is an early-stage, community-developed project. Support is best-effort and no response time is guaranteed.

## Where to ask

- **Bug reports and reproducible problems:** https://github.com/NotY215/NotYVOS/issues
- **Questions and design discussion:** use GitHub Discussions if enabled for the repository, or open an issue with a clear question.
- **Build instructions:** start with [docs/BUILDING.md](docs/BUILDING.md).
- **Architecture and implementation:** see [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and the source code.
- **Security issues:** follow [SECURITY.md](SECURITY.md) and avoid public disclosure of unpatched vulnerability details.

## Include useful details

When asking for help, include the relevant commit or branch, host operating system, build commands, expected behavior, actual behavior, and concise error output. For QEMU issues, include relevant configuration and steps to reproduce.

Remove passwords, tokens, private keys, personal data, and unrelated system details before posting logs. Search existing issues before creating a duplicate.

## Scope

NotYVOS is not an official Sony product and is not a general-purpose commercial support service. Features described as planned or incomplete may not work yet. Contributions and respectful community troubleshooting are welcome.
