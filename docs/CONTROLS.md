# Controls

The mapping lives in `src/xmb/input.hpp`.

| PS3 control | Keyboard | Action in the XMB |
|---|---|---|
| Left Stick Left / Right | Left / Right Arrow | Previous / next section |
| Left Stick Up / Down | Up / Down Arrow | Previous / next item |
| Right Stick Left / Down / Right / Up | H / J / K / U | Same as left stick |
| D-Pad Left / Down / Right / Up | Numpad 4 / 5 / 6 / 8 | Same as left stick |
| Cross | Z | Select / confirm |
| Circle | X | Cancel (closes dialogs) |
| Triangle | S | Jump to first item of the section |
| Square | A | Cycle theme colour |
| Start | V | Jump to Settings |
| Select | Space | Reserved |
| PS Button | Backspace | Power menu (Restart / Shut Down / Cancel) |
| L1 / R1 | L / R | Previous / next section |
| L2 / R2 | Right Shift / Right Ctrl | Page up / page down (5 items) |
| L3 / R3 | Left Shift / Left Ctrl | Reserved |

Mouse: move = highlight item, left click = select/activate, right click = cancel, wheel = scroll items,
Shift+wheel = switch sections.
