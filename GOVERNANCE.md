# Governance

## Current project model

NotYVOS is maintained as an independent, maintainer-led project under the GitHub account [NotY215](https://github.com/NotY215). There is no established foundation, elected committee, or formal multi-maintainer council unless the repository explicitly announces one.

## Decision-making

The maintainer coordinates the roadmap and makes final decisions on scope, releases, repository policy, and whether contributions are accepted. Decisions should consider technical merit, maintainability, project goals, security, accessibility, and legal obligations. Discussion and review are encouraged, but opening an issue or pull request does not guarantee acceptance.

## Contributions and review

Contributors can propose changes through issues and pull requests. The maintainer may request revisions, tests, documentation, or additional review before merging. Changes that affect architecture, licensing, security, or project direction should be discussed before implementation when practical.

## Releases

The maintainer determines release readiness and publishes releases or milestones when appropriate. The project may change its release process as it matures. A merged change or roadmap entry is not, by itself, a guarantee that a feature is complete or supported.

## Conflicts and conduct

Participants are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md). The maintainer handles conduct reports and may restrict participation when necessary. If a report concerns the maintainer, use available GitHub reporting mechanisms.

## Changes to governance

This document may be revised as the contributor community and project structure evolve. Significant changes should be documented in the repository.
