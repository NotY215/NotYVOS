# Governance

NotYVOS is maintained by **NotY215 (Shreyas Mishra)**.

The maintainer controls kernel/runtime architecture, roadmap, releases, licensing and final merge decisions. Changes affecting ABI, storage formats, hardware drivers, PS3 runtime behavior or security should include documentation and appropriate tests.

The project keeps user-supplied PS3 firmware separate from distributed source and does not redistribute Sony private keys or decryption bypasses.
