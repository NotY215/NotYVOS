# Contributing

NotYVOS is a native x86-64 operating system and PS3 runtime project using C/C++, x86-64 assembly, Clang/LLVM, LLD, CMake and Limine.

Read docs/build.md, docs/architecture.md, docs/testing.md and docs/roadmap.md before making system-level changes. Preserve kernel/user separation, firmware boundaries and the existing hardware/runtime architecture.

Test affected build presets and VM paths. Do not commit private firmware, proprietary keys, generated disk images or unrelated binaries.
