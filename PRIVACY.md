# Privacy Policy

Last updated: 2026-10-09

## Scope

This policy describes privacy expectations for the NotYVOS source repository and project-provided software. NotYVOS is a development-stage operating system and PS3 runtime project.

## Source Repository

- The project does not intentionally require users to submit personal information to build or run the source code.
- Do not include passwords, access tokens, private keys, personal addresses, or other sensitive information in issues, pull requests, logs, screenshots, or commits.
- Public issues, pull requests, discussions, commits, and other contributions may be visible to anyone.

## Software and Network Activity

NotYVOS is under active development. Network behavior may depend on the component, driver, build configuration, or third-party software a user chooses to install or run. This policy is not a guarantee that every component or third-party dependency is free of telemetry or network activity.

Review relevant source code and third-party privacy policies before using optional network-connected components. Do not assume that a development build is suitable for sensitive data.

## Third-Party Services

GitHub and other services used to host, build, distribute, or discuss the project may collect information according to their own policies. NotYVOS does not control those services or their data handling.

Third-party components are governed by their respective terms and privacy policies. Refer to the repository's third-party notices and license information.

## Reports and Contributions

If you discover that project code collects or exposes personal information unexpectedly, report it through the private security reporting process described in [SECURITY.md](SECURITY.md) when appropriate. Avoid publishing personal or sensitive data in a public report.

## Changes

This policy may be updated as NotYVOS capabilities and data-handling behavior change. Check this file for the latest version.

## Contact

For project questions, follow [SUPPORT.md](SUPPORT.md). For potential security or privacy vulnerabilities, follow [SECURITY.md](SECURITY.md).
