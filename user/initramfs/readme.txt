NOTYVOS initramfs
=================
This archive is loaded by Limine as a boot module and mounted by the kernel
as the in-memory root filesystem.

Current packaged files include:
  hello.txt
  readme.txt
  hello.elf

When a Wallpaper/1.png source or pre-converted wallpaper.raw is available,
wallpaper.raw is also packaged.

The persistent NYFS filesystem is mounted separately at /disk.
